Команды для консоли браузера

Открой F12 и вкладку Console. Команды считывают поля в том же порядке, что в предоставленном образце.
// Фамилия
document.getElementsByTagName('p')[1].childNodes[1].innerText

// Имя
document.getElementsByTagName('p')[2].childNodes[1].innerText

// Год рождения
document.getElementsByTagName('p')[5].childNodes[2].innerText
